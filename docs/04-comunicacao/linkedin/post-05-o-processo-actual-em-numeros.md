# Post 5 — 3 a 30 dias. O trabalho leva 4 horas.

**Gancho:** dois números em tensão
**Ideia única:** o problema não é o trabalho, é a espera — e a matemática das etapas explica tudo
**Etiquetas:** #BankingHub #BPM #Angola #MelhoriaDeProcessos #Banca

---

Abrir uma conta bancária em Angola leva entre 3 e 30 dias.

O trabalho real leva 4 horas.

Toda a diferença é espera.

Fui medir onde é que essas horas se transformam em semanas. E o resultado não é aquilo que se costuma culpar.

Não é a burocracia do formulário. É o número de vezes que o processo muda de mãos.

Conta com atenção:

Balcão → compliance, para verificar se o cliente é uma figura política.
Compliance → balcão, com a resposta por e-mail.
Balcão → sistema central, a copiar os dados do papel à mão.
Balcão → back-office, em malote.
Back-office → balcão, quando algo está errado.
Balcão → arquivo físico, no fim.

Oito passagens de mão em onze passos.

Cada passagem é um lugar onde o processo para e onde a informação se perde. Ninguém está a trabalhar. A pasta está à espera de alguém que está a fazer outra coisa.

Agora o número que me fez parar.

Se cada uma das 11 etapas correr bem 90% das vezes, a probabilidade de o processo inteiro correr bem não é 90%.

É 0,90 elevado a 11. Ou seja: 31%.

Duas em cada três contas passam por pelo menos um erro no caminho.

E é assim que se explica uma coisa que ouço muito nos bancos: "cada área está a funcionar bem". Está mesmo. O problema é que 90% onze vezes seguidas dá 31%.

Não é contradição. É multiplicação.

Uma nota de honestidade, porque acho que importa: estes números são o padrão do sector, não uma medição feita numa agência concreta. O próximo passo é ir medir 30 processos reais, com cronómetro, e sentar-me com quem faz aquilo todos os dias.

Até lá, é hipótese. E prefiro dizer isso do que apresentar uma estimativa como se fosse um facto.

Quem trabalha com processos: já calculaste a eficiência real de algum? O número quase sempre assusta mais do que se espera.
