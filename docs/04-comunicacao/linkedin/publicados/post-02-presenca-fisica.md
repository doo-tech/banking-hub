## Conteúdo (recuperado)

"Estou a iniciar um novo projecto centrado na automatização bancária aqui em Angola e decidi documentar o processo. O objetivo é combinar o Java e o Camunda para criar fluxos de registo e de pedido de crédito que sigam rigorosamente o Aviso 01/2023 do Banco Central de Angola (BNA)."

O post prossegue mencionando: tradução de normas regulatórias para modelos BPMN, passos de implementação técnica, integração com Android nativo, e arquitectura de sistemas distribuídos em serviços financeiros.

Temas: automatização bancária, Java e Camunda, conformidade com o Aviso 01/2023, modelação BPMN, desenvolvimento Android nativo, sistemas distribuídos.
